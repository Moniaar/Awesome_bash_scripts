# Awesome_bash_scripts
A collection of all bash scripts I am using in my terminal to enhance my work flow.

1. Locate your ./bashrc file after going to the root directory using the following command:
```
ls -a ~
```
2. Open it using your fav editor, ex: vim ~/.bashrc 
3. Add the scripts you want to it
4. Source the file using the following command: 
```
source ~/.bashrc
```
